# Progressive disclosure

## Context

Surfaced as an area of interest during early design thinking about Phase0.

## Body

Progressive disclosure is a design strategy that sequences information and options so users encounter complexity only as they need it. We want to investigate how this principle could apply to Phase0 — for example, how the facilitator surfaces modeling concepts, how artifact complexity is introduced over the course of a session, or how the instruction set itself could be layered so new users aren't overwhelmed.

Open questions:

- Where in the facilitation flow does cognitive overload risk peak?
- Could lenses be introduced progressively rather than presented as a complete graph up front?
- How should artifact forms scale — simple templates first, full structure later?
- Does progressive disclosure conflict with the Socratic style (which relies on the user engaging with concrete proposals early)?
